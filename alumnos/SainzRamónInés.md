# Por qué decidí estudiar ASIR
## *Por Inés Sainz Ramón*

### Contexto
Cuando terminé el Bachillerato de Ciencias de la Salud en el instituto, epezé a mirar qué opciones tenía. Entre ellas encontré [42 Madrid](https://www.42madrid.com/). 
42 Madrid es un campus de programación internacional en el que aprendí a programar en varios lenguajes de programación:
- C
- C++
- Python
- Typescript. 

También aprendí otras cosas útiles como:
- Github
- Las bases de las subredes
- Docker
- Máquinas virtuales
- HTML
- CSS
- Babyloon
- Tailwind.

Una vez terminé el **Common Core** en 42, que es la parte básica que todo el mundo debería de saber para asentar las báses de programación emmpezé a mirar otra vez, qué opciones tenía.

### ASIR Administración de Sistemas Informáticos y Redes
Como gracias a 42 ya tenía las bases dde programación asentadas y meterme a un grado superior de programación no tendría muchoo sentido, porque los conocimientos ya los tenía, miré que otros grados relacionados con tecnología había. Y gracias a eso encontré el de Sistemas y Redes, que me llamó mucho la atención y decidí que era el grado que iba a empezar.
