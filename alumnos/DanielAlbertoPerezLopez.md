# Mi motivación para estudiar ASIR

Elegí estudiar **Administración de Sistemas Informáticos en Red (ASIR)** porque me apasiona la *infraestructura tecnológica* y el funcionamiento de los servidores.

> "La informática no se trata solo de ordenadores, sino de resolver problemas."

### Objetivos del curso
- Aprender a administrar sistemas operativos Linux y Windows Server.
- Configurar servicios de red como DNS, DHCP y servidores web.
- Dominar el control de versiones con `git`.
